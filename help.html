AstroPet2Lox einrichten

  1. Unter Einstellungen die E-Mail und das Passwort deines AstroPet-Kontos eingeben und Speichern und verbinden wählen. Bereits gespeicherte Zugangsdaten bleiben erhalten, wenn du die Felder leer lässt.
  2. Falls AstroPet eine Bestätigung verlangt, E-Mail-Code anfordern wählen und den sechsstelligen Code bestätigen. Die E-Mail wird erst durch diesen Klick angefordert.
  3. Bei mehreren Geräten die gewünschte Katzentoilette auswählen. Das Plugin veröffentlicht die Werte dieses Geräts.
  4. Im LoxBerry-MQTT-Gateway einen Miniserver einrichten und die Weiterleitung aktivieren. Das Plugin registriert das Abo astropet2lox/# und verwendet den vorhandenen MQTT-Broker.
  5. In Loxone Config virtuelle Eingänge mit den Namen aus MQTT-Variablen anlegen, etwa astropet2lox_weight_kg. Das Plugin legt keine virtuellen Eingänge in Loxone Config an.

Der Hintergrunddienst fragt das Gerät automatisch ab. Standard: alle 60 Sekunden. Diese Browserseite muss dafür nicht geöffnet bleiben. Zum Pausieren die automatische Abfrage abwählen und Nur Einstellungen speichern wählen. Geräteverbindung trennen entfernt die Geräteverbindung; Browsersitzung löschen entfernt nur die kurzlebige Anmeldebestätigung im Browser.

Werte richtig verwenden

MQTT-Werte werden gespeichert (retained) und können nach einer Unterbrechung noch vorhanden sein. Verwende Gerätewerte nur bei astropet2lox_availability=1 und astropet2lox_data_valid=1. availability beschreibt den MQTT-Hintergrunddienst; data_valid beschreibt die erfolgreiche, ausreichend neue Geräteabfrage bei online erreichbarem Gerät.

astropet2lox_heartbeat_counter ändert sich normalerweise alle zehn Sekunden. Überwache ihn in Loxone mit einem Watchdog, beispielsweise mit 45 Sekunden Zeitüberschreitung. Er bleibt auch auf Eingängen mit begrenzter Zahlengenauigkeit eindeutig; heartbeat enthält zusätzlich die Unix-Zeit.

  • Gewicht: weight_kg ist das zuletzt gemeldete Gewicht. weight_available, weight_reported_at und weight_age_seconds helfen bei der Verwendung. Eine neue Geräteabfrage bedeutet kein neues Wiegen.
  • Besuche: visits_today nur zusätzlich bei visits_today_valid=1 verwenden. Die Tagesgrenze folgt der Zeitzone des Geräts. last_visit_duration_seconds ist die zuletzt gemeldete Besuchsdauer.
  • Streuwert: litter_level_percent nur zusätzlich bei litter_level_valid=1 verwenden. Gültigkeit: heutiger Gerätetag und höchstens 180 Sekunden seit der Meldung. Das Geräteschema erlaubt Werte bis 250; es wird keine zusätzliche Begrenzung auf 100 vorgenommen.
  • Zustand und Fehler: Unbekannte Zustandsnummern und Bits werden als Zahlen ausgegeben. Ihre Bedeutung wird nicht geraten. Ein Füllstand des Abfallbehälters lässt sich daraus nicht verlässlich ableiten.
  • Rohwerte: dp_-Themen folgen dem tatsächlichen Geräteschema. Fehlende Messwerte bleiben fehlend; ein Gedankenstrich in der Tabelle ist kein Messwert 0. Verfügbarkeit und Meldezeit stehen bei den beschriebenen Variablen.

Die vollständige Liste mit MQTT-Thema, Loxone-Name, Einheit und Gültigkeit steht im Tab MQTT-Variablen.

Wenn keine Werte ankommen

Den Verbindungsstatus, die Geräteauswahl, das MQTT-Gateway und die Miniserver-Konfiguration prüfen. Unter Protokolle stehen Meldungen des Hintergrunddiensts. Zugangsdaten werden auf dem LoxBerry gespeichert und nach dem Speichern nicht wieder in das Formular eingesetzt. Erforderlich sind LoxBerry 4, 64 Bit, PHP ab 7.4 sowie cURL, OpenSSL und zlib. Die Oberfläche nutzt direkt das vorhandene PHP des LoxBerry. Das Plugin installiert keine zusätzliche PHP-Version.

Die Anbindung liest Daten. Sie beruht auf der AstroPet-App 1.0.22 und einem privaten, inoffiziellen Dienst. Änderungen an diesem Dienst können eine Anpassung des Plugins erfordern.

Setup in English

Enter your AstroPet credentials under Settings and choose Save and connect. Blank fields preserve saved credentials. If required, request the email code explicitly and confirm it. Select your device when the account contains multiple devices.

Enable Miniserver forwarding in the LoxBerry MQTT gateway. The plugin registers astropet2lox/# on the existing broker. Create virtual inputs in Loxone Config using the names listed under MQTT variables, such as astropet2lox_weight_kg.

The background worker polls automatically, normally every 60 seconds. Only use device values when availability=1 and data_valid=1. Also check each value's availability, report time and validity. Weight and duration are the last reported measurements. Daily visits require visits_today_valid=1; litter readings require litter_level_valid=1. Retained MQTT values may remain after disconnection. Unknown fault bits and state numbers have no inferred meaning.

Monitor astropet2lox_heartbeat_counter using a Loxone watchdog, for example with a 45-second timeout. The counter normally changes every ten seconds; heartbeat additionally contains Unix time.

Requires LoxBerry 4, 64-bit PHP 7.4 or newer, cURL, OpenSSL and zlib. The interface uses the PHP runtime already provided by LoxBerry. The plugin installs no additional PHP version. This unofficial, read-only integration is based on AstroPet app 1.0.22.
